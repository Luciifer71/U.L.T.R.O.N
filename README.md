# U.L.T.R.O.N.

<sub>voice. memory. presence.</sub>

A personal AI assistant taking shape inside the machine.
Built around spoken requests and controlled desktop actions, with a visual identity of its own.

**v1 / in development**

Windows first. Still being tested, refined and made reliable for everyday use.

---

### `~/capabilities`

- Speak naturally to request supported desktop actions.
- Open applications and find files in a folder you specify.
- Ask for system statistics, time and everyday local information.
- Receive read-only email and calendar updates after connecting your account.
- Open websites and search the web.

A custom particle-based interface responds to the assistant’s activity.
Voice reliability, visual performance and experimental media playback are still being refined.

### Run

Start with the [setup guide](docs/getting-started.md). For an existing configured installation:

```powershell
.\start-ultron.cmd
```

Wait for `STANDBY MODE`, then say **“Hey Ultron.”**
Stop existing components before restarting.
